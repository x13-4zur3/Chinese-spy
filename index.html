Setup

Run it locally or deploy it to the cloud

1. Create the bot

Create a bot at the Discord developer portal, then enable Message Content Intent and Server Members Intent.

2. Configure environment

Copy .env.example to .env and set your DISCORD_TOKEN.

3. Install dependencies

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

4. Launch bot

python bot.py
